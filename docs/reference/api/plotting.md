# Plotting API

The non-underscored functions in `wavekernelrt.core.analysis_images` form the
supported public plotting interface. This includes both the named data-product
wrappers and the lower-level drawing functions. Import the module as a grouped
namespace:

```python
from wavekernelrt.core import analysis_images
```

See [Plotting and visualization](../../guides/plotting.md) for a function
chooser, orientation rules, and reduction behavior.

::: wavekernelrt.core.analysis_images

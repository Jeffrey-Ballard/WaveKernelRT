# Documentation asset provenance

The figures in this directory were created by Jeffrey Ballard using
WaveKernelRT and the publicly available SWellEx-96 experiment data. They are
original project-generated documentation artifacts, not figures copied from
the publications cited by WaveKernelRT.

The underlying SWellEx-96 recordings are not distributed with this repository.
Users obtain those recordings separately from the SWellEx-96 experiment
website, as described in the
[SWellEx-96 workflow](../examples/swellex96.md).

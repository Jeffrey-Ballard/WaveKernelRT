# WaveKernelRT examples

The examples are organized into two groups:

- `basic_geometries_and_beampatterns/` contains self-contained array geometry,
  shading, and beampattern demonstrations.
- `swellex96/` contains complete processing and visualization workflows for the
  external SWellEx-96 experimental dataset.

Start with the [examples guide](../docs/examples/index.md) for prerequisites,
run commands, required data, and expected outputs.
